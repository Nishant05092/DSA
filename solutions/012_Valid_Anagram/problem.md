# Valid Anagram

**Topic:** String  
**Difficulty:** Easy

## Problem

Given two strings s and t, return true if t is an anagram of s and false otherwise.

## Example

### Input
`s = "anagram", t = "nagaram"`

### Output
`true`

## Approach

Count the frequency of each character in both strings and compare the counts.

## Complexity

- Time: `O(n)`
- Space: `O(1)`

## Interview Tip

Frequency counting is one of the most common string problem patterns.
